# sy/bootstrap

A library for starting to create a website. Used in [sy/project](https://github.com/syframework/project)

## Installation

```bash
$ composer require sy/bootstrap
```

## Documentation

- [Form](https://github.com/syframework/bootstrap/wiki) — form components and submission flow
- [API](https://github.com/syframework/bootstrap/wiki/API) — HTTP API routing, responses and security
- [URL Converters](https://github.com/syframework/bootstrap/wiki/URL-Converters) — clean URLs, converter ordering and `Url::build()`
